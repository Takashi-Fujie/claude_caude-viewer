# SPEC-CHAT — セッション一覧とチャットビューア（基本仕様書）

担当 Issue: #6

## ゴール

会話を読みやすく整形して表示し、横断検索できるようにする。

## できること

- 左にセッション一覧（プロジェクト絞り込み・検索）、右に会話ビュー
- ツール呼び出しと実行結果は折りたたみ表示
- compact やターン区切りを会話の区切りとして表示
- sidechain / subagent は分岐として展開
- メッセージ単位のトークン数と推定コストを表示
- 全セッション横断の全文検索

## 人間の確認方法

画面のレンダリング結果と Playwright E2E（Issue #10 導入後）で確認する。詳細は Issue #6 着手時に具体化する。

実装方針・受け入れ基準は [docs/design/CHAT.md](../design/CHAT.md)。
