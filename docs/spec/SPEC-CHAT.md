# SPEC-CHAT — セッション一覧とチャットビューア

担当 Issue: #6

## ゴール

会話を読みやすく整形して表示し、横断検索できるようにする。

## 方針

- 左: セッション一覧（プロジェクト絞り込み・検索）、右: 会話ビュー
- 長い会話は仮想スクロール（`@tanstack/react-virtual`）
- ツール呼び出しと実行結果は折りたたみ表示
- `system.compact_boundary` と `system.turn_duration` を会話の区切りとして表示
- sidechain / subagent は分岐として展開
- メッセージ単位のトークン数と推定コストを表示
- 全文検索は転置インデックスを作らず、対象ファイルへのストリーム grep で行う（131MB 規模なら十分速く、更新コストもかからない）
