# SPEC-DASH — ダッシュボード（基本仕様書）

担当 Issue: #7

画面イメージの正本: [docs/mockups/viewer-mock.html](../mockups/viewer-mock.html)（2026-08 のモック合意で確定）

## ゴール

**Overview → プロジェクト → セッション**の 3 階層ドリルダウンで、全体俯瞰から気になる作業へ一直線に降りられるようにする。ナビは「Overview / Tools & Agents / 設定・定義」の 3 項目のみとし、プロジェクト画面・セッション分析画面はドリルダウンで到達する（パンくずで戻る）。

## できること

1. **Overview** — 期間フィルタ、総コスト（推定）、総トークン、モデル別利用状況のドーナツ 2 つ（トークン / コスト）、日次トークン積み上げ + コスト折れ線、プロジェクト一覧
2. **プロジェクト画面** — 日次モデル別トークン積み上げ + コスト折れ線、セッション一覧
3. **Tools & Agents** — ツール別ランキング、失敗率、プロジェクト別ツール利用、MCP サーバ別内訳、hook 発火履歴、エージェント定義 × 起動実績（未使用検出）、Skill 呼び出し履歴、subagent 実行トレース

## 表示上の約束

- **チャートの共通操作**: チャートの縦帯（1 日 = 1 帯）クリックで、直下の一覧をその日に対応する項目だけに絞り込む。Overview では日付 → プロジェクト、プロジェクト画面では日付 → セッション。選択帯はハイライトし、解除チップを表示する。再クリックでも解除できる。活動が無い日は「該当なし」を明示する
- **トークンとコストは二軸グラフにしない**。x 軸（日付）を共有した上下 2 パネル（上: 積み上げ棒、下: コスト折れ線）で並べる
- Overview の積み上げは**トークン種別**（input / output / cache write / cache read）、プロジェクト画面の積み上げは**モデル別**。モデルの色はドーナツ・積み上げで共通の固定割り当てとする
- コストは常に「推定」と明示し、キャッシュ内訳を必ず表示する（SPEC-COST の表示上の約束）
- **未知モデルは警告バナー**で件数と「コストに含まれていない」ことを明示する（0 円扱いで黙らせない）
- 設計基準幅は MacBook Pro 14 インチの論理解像度 **1512px を最小**とし、それ未満は縮めず横スクロールで比率を保つ
